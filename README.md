# Nuvri Legal (`minilingo-legal`)

Este repositorio contiene los documentos legales públicos de la aplicación **Nuvri** (anteriormente MiniLingo), alojados para ser accesibles desde la aplicación móvil, la web pública y las tiendas de aplicaciones (Google Play Store y Apple App Store).

## Contenido

* **[Términos y Condiciones de Servicio (`terms.html`)](./terms.html)**: Define los conceptos clave del servicio, las características y funciones de Nuvri (Diccionario Personal, importación CSV, sistema SRS Leitner, 8 modos de juego, niveles MCER A1–C2 y recordatorios con audio), las reglas de uso aceptable y las condiciones legales.
* **[Política de Privacidad (`privacy.html`)](./privacy.html)**: Detalla qué datos se recopilan, su finalidad pedagógica y técnica, los servicios de terceros utilizados (Firebase, AdMob, Google/Apple Sign-In, IA) y los derechos de privacidad del usuario.
* **[Instrucciones de Eliminación de Datos (`delete.html`)](./delete.html)**: Guía paso a paso sobre el flujo de eliminación inmediata y permanente de cuenta mediante verificación OTP por correo electrónico.
